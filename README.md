# Portfólio — Rachel Silva

Site de portfólio responsivo criado com HTML, CSS e JavaScript.

## Como abrir no computador
1. Baixe os arquivos.
2. Extraia o ZIP.
3. Abra `index.html` no navegador.

## Como publicar gratuitamente no GitHub Pages
1. Crie ou entre na sua conta em https://github.com/
2. Clique em **New repository**.
3. Nome sugerido: `portfolio-rachel`
4. Marque **Public** e crie o repositório.
5. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` para o repositório (Add file → Upload files).
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
9. Aguarde a publicação. O GitHub mostrará o endereço do site na própria página Settings → Pages.

O endereço costuma seguir este formato, mas só passa a existir após publicar:
`https://SEU-USUARIO.github.io/portfolio-rachel/`
